HLA-PROTBBERT / MULTI-ENCODER BRIEF (December 2025)

Project scope
- End-to-end toolkit to encode HLA alleles with multiple protein language models and analyze locus structure.
- Primary outputs: cached embeddings per encoder and locus-level plots (PCA, t-SNE, UMAP).
- Default data source: current IMGT/HLA protein sequences (`data/processed/hla_sequences.pkl`).

Encoders supported (src/models/encoders)
- ProtBERT (768-dim, 420M params)
- ESM-2 650M (1280-dim)
- ProtT5 XL (1024-dim)
- Ankh Base (768-dim, ~50M)
- Ankh Large (1536-dim, ~650M)
- All share the `HLAEncoder` base: caching, SSL toggle, optional HF token, locus filtering.

Pipeline snapshot
- `run_complete_pipeline_all_encoders.sh` orchestrates:
  1) Directory creation
  2) IMGT/HLA download (`scripts/update_imgt.py`)
  3) Embedding generation for all 5 encoders (`scripts/generate_embeddings.py`)
  4) Locus analysis for ProtBERT (`scripts/run_locus_analysis.py`) -> plots under `data/analysis/locus_embeddings/class1/plots`
  5) Summary stats (dimensions + allele counts printed)
- SSL bypass and Ankh backend can be set via flags/env (`--disable-ssl-verify`, `--ankh-backend`).

Current data snapshot (Dec 2025 run)
- Total alleles: 26,000
- Class I focus in deck: A 5,489; B 6,584; C 5,206 (17,279 combined)
- Class II counts: DRB1 2,607; DQB1 1,824; DPB1 1,782 (others in long tail)

Visualization defaults (scripts/analyze_locus_embeddings.py)
- UMAP: n_neighbors=15, min_dist=0.1
- t-SNE: perplexity=30, learning_rate=200
- PCA: 2 components
- Batch size defaults to 8; GPU auto-detection in encoders.

Key talking points for slides
- Multi-encoder flexibility: speed/accuracy trade-offs, ensemble-ready.
- Caching avoids repeated downloads/encodes; pipeline resumable.
- Locus plots show clear clustering of major allele families; aligns with HLA nomenclature.
- Clinical: supports better similarity search/cross-reactivity hypotheses.
- Technical: extensible encoder base class; CLI + scripts + examples.
